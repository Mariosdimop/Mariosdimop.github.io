Projects

Things I've built to learn by doing.

Python 3 · CLI (bash) · Cybersecurity

python_encryption

A command-line tool that encrypts and decrypts files and entire directory trees using hybrid RSA–AES encryption. Every file gets its own random AES key and nonce; that key is then sealed with an RSA public key. Passwords, keys and counters live in the operating system's vault through keyring, never in plain files.

  • Encrypt / decrypt single files or nested directories
  • Password change without re-encrypting everything
  • “Reboot” option that rotates the RSA key pair
  • Secrets stored in the OS keyring

A learning project — built to sharpen my Python and security fundamentals, not yet battle-tested for critical data.
